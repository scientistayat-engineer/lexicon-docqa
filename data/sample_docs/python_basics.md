# Python Basics
Python is a high-level, interpreted programming language known for readable syntax. Variables are dynamically typed, so you do not declare a type before using a name.

Lists are mutable sequences written with square brackets. Tuples are immutable sequences written with parentheses. Dictionaries store key-value pairs and give fast lookups by key.

Functions are defined with the def keyword. Virtual environments isolate project dependencies, and pip installs packages from PyPI.

# Machine Learning Intro
Machine learning lets computers learn patterns from data instead of following hand-written rules. Supervised learning uses labelled examples, for instance classifying emails as spam or not spam. Unsupervised learning finds structure in unlabelled data, such as clustering customers.

A model is trained on a training set and evaluated on a separate test set to check how well it generalises. Overfitting happens when a model memorises the training data and performs badly on new data.

Large language models are neural networks trained on huge text collections to predict the next token. Prompts guide their behaviour without retraining.
